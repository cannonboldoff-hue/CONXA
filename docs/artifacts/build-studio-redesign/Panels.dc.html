Living with a native browser view

  • Nothing from the app can draw over the browser region. Menus that would overlap it open toward the workspace instead.
  • While a dialog is open, the browser region is hidden and shows “Browser hidden while this dialog is open”.
  • The region is resized by the app on every divider move and window resize; the page underneath reflows like any browser.
  • Popups and new tabs the site opens appear as tabs in the panel’s footer, never as stray windows.
  • If attaching the browser fails, the run falls back to its own window and the panel says so.

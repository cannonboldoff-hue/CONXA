Steps recorded each pass: click Username box, type "Admin", click Search.

1. natural (caption drawn with the box, as OrangeHRM really does)
   natural_before_fix.json : box click "Username", type "Username", Search button "Username"  <- WRONG caption on the button
   natural.json (after fix): box click "Username", type "Username", Search button none
   Cause: captureAssociatedLabel rule 5 takes the first <label> under the element's grandparent; for the Search
   button the grandparent is the whole filter form. Fix: rules 4-5 (neighbouring <label>) skip buttons and links.

2. late, caption removed before the click and put back 150 ms later (late150.json)
   click arrived with no caption; an amendment then added "Username" (arrivals list) -> the _lateLabel /
   _apply_amend_sync path works live. Type step: "Username". Search button: none.

3. late, caption put back 1500 ms later (late1500.json)
   click and type both arrived with no caption and no amendment came: each step re-reads once, right after the page
   goes quiet (click: <=250 ms, typing: <=1.5 s after the type step is sent), which is before the caption returns.
   Known limit, simulated only; the real OrangeHRM page draws its captions with the boxes.

## Root causes and decisions
- Nothing failed that needs a fix; no product file was changed. Tools/evidence only under `docs/testing/`.
- Harness notes: (1) a mock-Clerk session for the dashboard needs `CLERK_API_URL` (not `CLERK_JWT_KEY`, which `@clerk/nextjs` here ignores) and cookies suffixed with `sha1(publishable key)` base64url[:8]; (2) delta sync is rate limited to one call per 5 minutes per sync token (429), so a manual delta call before `bootstrap.js sync` makes the sync look failed; (3) the app-layer drill needs `runtime/vendor` and `node_modules` junctions in the isolated copy of the host.
- Findings to file in `TODO.md` (all S3, none block a pilot): startup does not require `SKILL_CORS_ALLOWED_ORIGINS` (dead check), `CONXA_ADMIN_TOKEN`, `SKILL_CLERK_AUTHORIZED_PARTIES`, `CLERK_SECRET_KEY` in prod; unreachable DB gives a silent hang at startup; member sees owner buttons on Billing/Team; "Skill pack not found" console error on an empty workspace; a bad app layer is re-downloaded on every launch until replaced; spec/docs still say "promotion" for updates.

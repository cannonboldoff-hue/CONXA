# Fix Log — 2026-10-17

**Designed a new, conversation-led Build Studio — 2026-10-17**
We drew a full redesign of Build Studio where each workflow gets its own ongoing conversation, like a chat thread that remembers everything. You create a workflow, record it, answer a few plain questions, test it while watching the real browser beside the conversation, and then approve it, all in one place. This is a design for review only; nothing in the app has changed yet. A copy of the design boards is saved with the project's other design work.
— 2026-10-17

**Reworked the Build Studio design after review — 2026-10-17**
We changed the design based on feedback. The editing screen now matches the one people already use. Publish sits right under New workflow. Clicking the workspace name opens a settings window like Claude Desktop's. Unfinished workflows wait in a new Chats list and move into their group after their first passing test. Recording now happens in a browser that slides in beside the conversation, and it opens on the app's sign-in page first when needed, just like Conxa Execute.
— 2026-10-17

**Made the Chats and Groups lists foldable in the design — 2026-10-17**
The Chats and Groups headings in the left sidebar now work like drop-downs. One click folds a list away and another click opens it again. This keeps the sidebar tidy when someone has many chats or groups.
— 2026-10-17

**Removed the extra sign-in screen from the design — 2026-10-17**
The design had a separate screen just for signing back in to an app. Signing in now happens in the browser that opens for recording, so that screen did the same job twice. We removed it, and everything that pointed to it now goes to the recording screen.
— 2026-10-17

**Failed tests now fix themselves in the design — 2026-10-17**
When a test fails, Conxa now works out why, fixes the workflow and runs the test again on its own, right in the conversation. It keeps going until a test passes, up to three tries, then stops and asks for help. Every change it makes is listed and can be undone, and approving the workflow is still a person's decision.
— 2026-10-17

**Reviewed the new Build Studio design — 2026-10-17**
We looked over every screen of the redesigned Build Studio and wrote up what works and what doesn't. Nothing in the design was changed. The biggest concerns are that automatic re-testing can repeat real actions like sending an invoice, and that unfinished workflows are hard to find inside their group.
— 2026-10-17

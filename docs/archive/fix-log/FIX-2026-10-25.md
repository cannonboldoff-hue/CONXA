# Fix Log — 2026-10-25

**Rewrote the follow-up questions in everyday words — 2026-10-25**
After you record, Conxa asks a few questions, and they were full of tech words like "inputs", "runs" and "page address". Every question, answer choice and confirmation line now uses plain, friendly wording, like "Which of these are different every time?" and "You see the words … on the screen". One question also showed doubled quote marks around a name, which is fixed. Like swapping a form full of legal terms for one a friend would read aloud.

**Added a visual guide to how Conxa asks questions after recording — 2026-10-25**
There was no single place that explained what happens after a recording is compiled. Now there is a page with diagrams, written in everyday words, showing how Conxa checks the result against your description, how it writes the questions, where an AI model helps, and how the chat works. Like a map posted at the entrance of a building.

**Questions after recording now get a friendly rewrite for each workflow — 2026-10-25**
The follow-up questions used the same fixed wording for every workflow. Now an assistant rewrites them in plain, easy words, using the details of what you recorded. What each answer does is still fixed, and if the rewrite fails or looks wrong, the standard wording is shown instead. Like a helpful friend rephrasing a form, while the form itself stays the same.

**Recording no longer starts when a saved sign-in can't be confirmed — 2026-10-25**
Before, if the app couldn't tell whether a saved sign-in still worked, Conxa assumed it did and opened the recording anyway. Now it only starts once every app in the group is positively confirmed as signed in, and otherwise asks you to sign in again first. Like a doorman who checks your ticket is still valid, not just that you're holding one.

**Made the "Chats" and "Groups" headings in the left sidebar bigger — 2026-10-25**
The two section titles on the left were tiny and hard to read. They are now the same size as the items beneath them. Like turning a whisper-quiet label into a normal signpost.

**Removed the explanatory note about groups from the left sidebar — 2026-10-25**
The sidebar had a small paragraph under the Groups heading explaining what a group is. It is gone, so the list looks cleaner. Like taking a caption off a sign that already says what it is.

**Moved the "Record a workflow" box to the workflows side of the group page — 2026-10-25**
The box with the New workflow button used to sit under the sign-in list on the left. It now sits at the bottom of the workflows list on the right, where the new workflow will appear. Like putting the "add item" button right under the list it adds to.

**Moved the "Open workflow chat" button to the far right of each workflow — 2026-10-25**
The button used to sit to the left of the rename and delete icons. It now sits at the right edge, after them. Like putting the main exit at the end of the hallway where people expect it.

**The chat button on each workflow is now a clearly labelled button — 2026-10-25**
The way into a workflow's conversation was a tiny icon that was easy to miss. It is now a coloured button that says "Open workflow chat". Like swapping a small unlabeled doorbell for a big sign that says "Enter here".

**Removed the Inspector button from workflows on the group page — 2026-10-25**
Each workflow had a small folder button that opened a technical detail view. It is gone, leaving just the chat, rename and delete buttons. Fewer buttons means less guessing about which one to press.

**Removed the five-step row from each workflow on the group page — 2026-10-25**
Each workflow used to show a row of five step buttons, and the Record one opened a separate recording browser instead of the workflow's conversation. That row is gone, so the chat button is now the way into a workflow. Like taking down a confusing signpost so only the clear door is left.

**Added an "Open workflow chat" button to each workflow on the group page — 2026-10-25**
The Record step on a workflow opens a separate recording browser, so there was no obvious way to get back to the workflow's conversation. Each workflow now has a chat button beside its other action buttons that opens that conversation. Like a door marked "back to the main room" next to the one that leads out to the side workshop.

**The "What does the task do?" box on the new workflow page is now required — 2026-10-25**
The box used to be marked optional, so many people skipped it. Now the page asks for a short description before it lets you start recording, and shows a plain message if it is empty. This gives Conxa something to work from when it asks follow-up questions, like a job ticket that can't be filed without a one-line summary.

**Three small Studio and runtime gaps closed — 2026-10-25**
An optional input no longer shows as required on the test screen. A value that breaks an input's own format rule is now turned away with a plain message before anything runs, instead of being typed into the page. The helper's "wait for the file link" fix can now be added next to a conditional step instead of being rejected. Like a form that finally checks the box labelled optional, and a bouncer who checks the ID before the door opens.

It's like a mechanic checking you put in the right fuel before taking the engine apart.

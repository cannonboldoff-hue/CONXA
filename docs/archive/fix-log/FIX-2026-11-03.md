# Fix Log — 2026-11-03

**Wrote up a plain-language review of where we patched single recordings instead of fixing the root cause — 2026-11-03**
Several recent fixes were tuned to one website or one recording, like adjusting a recipe for one oven. The review lists each one, why it will not hold up for other apps, and what a lasting fix would look like. It also lists the parts that are already solid so nobody rebuilds them.
— 2026-11-03

**The workflow map now reads top to bottom, with bigger boxes and text — 2026-11-03**
The map used to run sideways, and its labels were too small to read comfortably. It now reads top to bottom, one row per step of the process, with larger boxes and text that wraps instead of spilling out. On laptop-sized screens the map fills the full width, and the details slide in from the side when you click a box.
— 2026-11-03

**The workflow guide is now a clickable map — 2026-11-03**
The guide used to be one long page to scroll through. It is now a map of boxes joined by arrows, one row for each party: the person, the Studio, the video service, the AI, and the customer's computer. Click any box to see what happens inside it and where it connects, or press "Walk through" to step through the whole path in order. Claude's own recording feature gets a matching map, plus a side-by-side view.
— 2026-11-03

**New visual guide to how a workflow is built, from recording to running — 2026-11-03**
There was no single place that showed every step between "record a task" and "a customer runs it". There is now one interactive page that walks through each stage, shows who decides what at each point (the software, the AI, or the person), and lets you try example questions. It also compares our approach with Claude's own "record a workflow" feature and lists what we could borrow from it.
— 2026-11-03

**Workflow steps now tell apart a tab you opened from a tab a click opened — 2026-11-03**
Before, both cases showed the same line, "A new tab opens", so you couldn't tell whether you did it or the website did. Now a tab you opened yourself reads "Open a new tab", and a tab that opened because of a click reads "The click opens a new tab". Like telling apart "I opened the door" from "the door opened when I stepped on the mat".
— 2026-11-03

**Removed the small arrows and indents from the workflow summary — 2026-11-03**
The step list in the chat used to push some lines to the right with a little arrow, such as "A file downloads" under a click. That made the list look messy and confusing. Now every step sits in one clean, evenly lined-up list. Like a to-do list where every item starts at the same edge.
— 2026-11-03

**Test steps now read like your workflow's own step list — 2026-11-03**
While a test ran, each line only said "Navigate", "Scroll" or "Click", so you couldn't tell which step was which. Now each line uses the same wording as the workflow's step list, such as "Open github.com" or "Click “New”", and follow-on steps are indented under the action that caused them. Like a recipe that says "whisk the eggs" instead of just "step 3: stir".
— 2026-11-03

**Fixed a download-then-upload workflow that never actually uploaded — 2026-11-03**
A workflow that downloaded a file from one site and uploaded it to another lost its upload step, because Studio mistook your file pick for something the website did on its own. Its test still "passed", because the only check was that the page address changed. Now the upload is kept and uses the downloaded file, and the summary says the workflow is done when the file is uploaded. Studio also tidies up repeated page loads again, asks about anything it noticed but couldn't see instead of only mentioning it, merges duplicate questions, shows your actual answers, keeps email addresses out of the chat, and shows the "watching the recording" and test steps cleanly. Like a removal van that now checks the box actually reached the new house, not just that it drove off.
— 2026-11-03

**Stopped recordings from picking up clicks you never made — 2026-11-03**
A recorded workflow could contain a step like clicking a Google account button that you never touched, because the website itself pressed it. The recorder now tells apart a click from a real person and a click from a website's own code, and leaves the second kind out of the workflow. This stops stray steps from sneaking in, whatever site you record.
— 2026-11-03

**Stopped asking about pauses and timing in a recording — 2026-11-03**
Before building a workflow, the Studio sometimes asked confusing questions like "88 seconds pass with nothing recorded, is it fine?" or "the video is ahead of the browser". Nobody but an engineer could answer them, and the only sensible answer was always "yes". These moments are now handled quietly in the background, and only questions about real choices in the task are asked.
— 2026-11-03

**Now warns you when a file was picked outside the browser — 2026-11-03**
If you picked or dragged in a file from a window outside the browser, the recording could not see which file it was, so the workflow could never repeat that step. The Studio now spots this moment in the video and asks one plain question: record that part again, or say no file was needed. Normal pauses and timing differences are still never asked about.
— 2026-11-03

**Helper assistants now run on a cheaper model — 2026-11-03**
When the coding assistant hands part of a job to a helper, the helper used to run on the same top-tier model. It now always uses the next model down: the mid-tier one under the top tier, and the smallest one under the mid tier. This keeps helper work cheaper and faster without changing the main assistant.
— 2026-11-03

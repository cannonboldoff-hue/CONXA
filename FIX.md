# Fix Log

> Rotated daily into `docs/archive/fix-log/` — see [INDEX.md](docs/archive/fix-log/INDEX.md) for older entries.

**The coding assistant now knows who Conxa is built for — 2026-11-08**
The assistant's instruction sheet never said who our users are. It now says Conxa is made first for non-technical people, with deeper controls one click away for technical people. This keeps new screens and messages simple by default without taking power-user tools away.
— 2026-11-08

**Shortened the instruction sheet the coding assistant reads before every task — 2026-11-08**
The assistant's instruction sheet had grown to the length of a long report, repeating detail that already lives in our technical guides. It is now about a sixth of the size and keeps only the rules that matter on every task, with pointers to the full guides. A shorter sheet means the assistant spends less time and money reading before it starts working.
— 2026-11-08

**The "your workflow is ready" message now explains things in plain words, whatever happened — 2026-11-08**
That message used to be a fixed script, so unusual cases (several things left out, a part we're unsure about, something you described that isn't in the workflow) read stiffly. Now an assistant writes it from the facts, and adds what to expect next: how many questions are coming, and that the test will ask for your inputs. If the assistant is offline or gets a fact wrong, the earlier plain message is shown instead, so nothing is ever missing.
— 2026-11-08
